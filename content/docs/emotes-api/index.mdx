---
title: Emotes API
description: Public read-only API for Twitch, 7TV, BetterTTV, FrankerFaceZ and Kick emotes.
---

The **Emotes API** provides public endpoints for global and channel emote
collections, platform channel identifiers and provider CDN redirects. Each
endpoint page includes parameters, response schemas, examples and an
interactive request panel.

## Base URL

```text
https://emotes-api.enhancer.at
```

## Endpoints

- [Get global emotes](/emotes-api/emotes/getGlobalEmotes) - global emotes grouped by platform and provider.
- [Get channel emotes](/emotes-api/emotes/getChannelEmotes) - channel-specific emotes with platform/provider filters.
- [Get channel identifiers](/emotes-api/channels/getChannelIdentifiers) - platform-native channel ids.
- [Get emote proxy redirect](/emotes-api/proxy/getEmoteProxy) - provider CDN redirect with caching headers.

Collection responses use a platform/provider matrix. A provider failure
contributes an empty collection without failing the aggregate response.
