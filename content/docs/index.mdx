**Enhancer** is a completely free, open-source browser extension that
supplements streaming platforms with valuable features we feel are missing.

Our philosophy is simple: if the platforms ever added these features
themselves, we would want them to be free for everyone too. **Every feature
available in Enhancer is free and will never change.**

## Where should I go?

**I am a user.** See [Installation](/general/installation) to set up Enhancer,
and check the [FAQ](/general/faq) for common questions.

**I am a developer.** Build on Enhancer with the [Enhancer API](/api), including
[Channels](/api/channels), [Users](/api/users) and [Badge images](/api/badge-images).
For chat emotes, see the [Emotes API](/emotes-api).
