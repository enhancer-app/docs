**Enhancer** is a completely free, open-source browser extension that
supplements streaming platforms with valuable features we feel are missing.

Our philosophy is simple: if the platform had built these features itself,
they would have been part of the free, standard experience.

## Where should I go?

**I am a user.** See [Installation](/general/installation) to set up Enhancer,
and check the [FAQ](/general/faq) for common questions.

**I am a developer.** Build on Enhancer with our public API: see the
[Channel](/api/aggregate), [User](/api/user) and [Badge](/api/badge-images)
references.
