**Enhancer** is a completely free, open-source browser extension that
supplements streaming platforms with valuable features we feel are missing.

Our philosophy is simple: if the platform had built these features itself,
they would have been part of the free, standard experience.

## Get started

Install Enhancer on your browser: see [Installation](/getting-started/installation).
